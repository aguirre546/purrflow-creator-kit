# PurrFlow Creator Kit

**One cat story → an animated short, five platform drafts and a portable creator kit.**

Built by **Victor Aguirre**, solo, **Technology Mafia**, for the **Craftsmanship** bucket at ManilaHack 2026. Live URL: https://purrflow-creator-kit.studio-builder.workers.dev/ (deployed and browser-verified November 12, 2026). Competition submission remains pending Victor's explicit instruction.

## Try it locally

Requirements: Node.js 22 or newer, npm, and a current desktop browser. Chrome or Edge is recommended for video recording. There are no npm package dependencies, environment variables, API credentials or paid services to configure. An install step is unnecessary.

```sh
npm test
npm start
```

Open **http://127.0.0.1:4328/**. Keep that terminal running while using the local app. The server binds only to the loopback interface. Serve the app over HTTP or HTTPS rather than opening `index.html` as a local file.

## A complete walkthrough

1. Choose a story template and edit its title, hook, setup and payoff. Choose Playful or Cozy voice and English or Taglish surrounding caption copy. Click **Build my creator kit**.
2. Play or scrub the animation and inspect its narrative text. Click **Render 15-second video** and keep the tab open until recording finishes. Controls are temporarily disabled during rendering.
3. Review the five platform tabs and edit the drafts. These are local template-based writing rules, not a connected language model.
4. Open **Content calendar**, choose a start date and three to five stories per day, then build the seven-day plan. **Use this brief** loads a planned story into the studio.
5. Export the creator kit. A newly rendered video is included when available. Individual SRT and calendar CSV downloads are also available.
6. Use each platform's own tools to publish or schedule. Confirm its format, visibility, caption and disclosure requirements before sharing.

Editing the story invalidates the old rendered video; rebuild and render again so the output agrees with the brief. English/Taglish mode adapts surrounding copy and preserves the entered story text.

## What it creates

- A silent procedural cat animation using one of **three visual plots**: bed versus box, shelf adventure or tiny chef. Changing text does not generate arbitrary new scenes.
- A nominal 15-second, 720 × 1280 vertical video recorded from the browser canvas, with narrative captions. MP4 is preferred when supported; WebM is the fallback. Codec, frame rate and measured duration depend on browser capabilities and load. WebM may need conversion for a chosen social destination.
- Five distinct editable drafts for Facebook, Instagram, YouTube, X and TikTok; timed SRT; story and workspace data; calendar materials; and a downloadable ZIP. The ZIP includes the current rendered video if it exists.
- A seven-day editorial plan containing **21–35 story briefs**, depending on the selected daily count. These are variations across three visual templates, not 21–35 unique generated animations or finished video files.

The **AI sample** tab previews a separate provided Google Flow video. It is not generated by this app and is excluded from creator-kit ZIP exports.

## Saving and data

**Save workspace** stores the draft in this browser's local storage. After rendering, the app also saves that video's matching workspace automatically and keeps the latest video in IndexedDB when browser storage is available. Reloading restores the video only when its saved reference and exact story match. Editing or rebuilding the story, selecting a template, or importing a JSON backup invalidates the previous video. Caption-only and calendar edits keep the video because they do not change its frames.

JSON backup and restore provide a portable draft copy; JSON backups contain no video. Download the video or full ZIP for a separate copy. If storage is full, blocked or unavailable, the app explains what could not be saved and keeps the current video available to download. Browser cleanup or eviction can remove drafts and cached videos. There is no account, cloud sync, remote database or social token collection.

## Scope and limitations

This rebuild provides a complete local creation and preparation workflow. It avoids the previous version's external dependencies; it does **not** solve Google Flow background generation, social OAuth authorization, Meta developer verification, paid API eligibility or always-on publishing infrastructure.

There is no automatic social publishing, social scheduling queue, audience analytics, measured peak-time optimization, live AI generation or unattended account switching. Calendar times are editable editorial targets in Manila time. Narrative captions are not speech transcription. A seven-day plan does not demonstrate seven days of unattended operation.

## Source and static deployment

| Path | Purpose |
|---|---|
| `dist/index.html`, `dist/style.css` | Responsive workspace and styles |
| `dist/app.mjs` | UI, local persistence, preview and download actions |
| `dist/core.mjs` | Story/copy rules, planning, validation, SRT and ZIP creation |
| `dist/renderer.mjs` | Original canvas illustration, animation and browser recording |
| `dist/video-cache.mjs` | IndexedDB video persistence, matching workspace references and stale-operation guards |
| `dist/assets/` | Credited reference artwork and provided AI sample |
| `test/` | Automated tests; browser media/UI checks are separate |
| `serve.mjs` | Dependency-free local static server |

For a static host, publish **`dist/`** as the site root. No build command is required. Preserve module MIME types and media assets. `dist/_headers` contains a restrictive Content Security Policy, framing protection, MIME sniffing protection, a referrer policy and disabled camera/microphone/geolocation permissions. Hosts that do not process `_headers` require equivalent header configuration. The local development server sets a smaller header set; it is not a production backend.
